# Kiethston Academy Website

## About the Project

Kiethston Academy is a fictional educational institution website. The website provides information about the academy, its faculties, admissions process and contact details.

## Technologies Used

* HTML5
* CSS3
* Google Fonts
* Unsplash images

## Pages

The website contains five pages:

* **Home** – Introduction to Kiethston Academy and Open Day information.
* **About Us** – Information about the academy, its vision, mission and values.
* **Faculties** – Information about the Science, Commerce and Engineering faculties.
* **Admissions** – Admission requirements and application process.
* **Contact Us** – Contact information, contact form and map.
